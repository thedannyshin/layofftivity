# Layofftivity

Small-group volunteering app for people rebuilding routine after a layoff.

## Development

```sh
git clone https://github.com/thedannyshin/layofftivity.git
cd layofftivity
npm i
npm run dev
```

Production: [layofftivity.vercel.app](https://layofftivity.vercel.app/)

## Built with

- TanStack Start
- TypeScript
- React
- Tailwind CSS
